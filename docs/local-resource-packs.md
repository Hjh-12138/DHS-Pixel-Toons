# 本地角色与场景资源包

打开动画条下方的「本地资源」，选择「导入资源包」。成功导入后自动应用；角色与场景可以分别选择，套装也可以一键应用。点击「试用示例」会导入薄荷机器人与月光庭院。点击「恢复默认」使用内置女孩和预制场景，已经导入的包仍保留在列表中。

资源和当前选择保存在当前客户端的浏览器存储中，重新打开相同客户端后恢复。Web、Desktop、不同浏览器和不同站点地址分别拥有自己的资源库；导入不会上传到服务器。清除网站数据会删除资源库，请保留原始资源包。

## ZIP 格式

可以直接导入 `examples/mint-robot.toons.zip`，也可以修改 `examples/mint-robot/` 中的模板后重新打包。将以下文件放在 ZIP **根目录**，不要再套一层目录：

```text
manifest.json
character.png
background.png
foreground.png   （可选）
```

包可以只包含角色、只包含场景，或两者一起。ZIP 内只接受配置文件、PNG 和 WebP，不支持上传脚本、SVG、远程图片地址或自定义模型请求。

最小角色包的 `manifest.json`：

```json
{
  "format": "dsh-toons-pack",
  "version": 1,
  "id": "my-cat",
  "name": "我的小猫",
  "author": "创作者名字",
  "character": {
    "atlases": { "main": "character.png" },
    "referenceHeight": 80,
    "actions": {
      "idle": {
        "loop": true,
        "stance": "standing",
        "frames": [
          {
            "atlas": "main",
            "x": 0, "y": 0, "w": 64, "h": 80,
            "anchorX": 32, "anchorY": 76,
            "durationMs": 1000
          }
        ]
      }
    }
  }
}
```

`id` 使用小写字母、数字、下划线或短横线，最多 64 个字符。同 ID 的有效新包会更新旧包；校验或保存失败时保留旧版本。`name` 是界面显示名称。

`atlases` 可注册 1 到 8 张图片，每帧的 `atlas` 引用其中一个名称。角色图片建议采用透明背景。`x/y/w/h` 是图集中的帧裁切范围；每个数都是源图片像素。`anchorX/anchorY` 相对于裁切后的帧左上角，分别表示身体根位置和落脚基线；所有帧应维持同一个身体根位置。缺省时采用水平中心和帧底部。

`referenceHeight` 决定人物的像素比例，建议填写站姿参考帧的高度，趴姿仍沿用该比例。`durationMs` 是本帧的显示时长，默认 240，范围 40 至 10000。`loop` 控制循环，成功与失败动作默认不循环。`stance: "prone"` 会在内置场景中采用趴姿的站位与书桌；其他情况使用 `standing`。

支持的动作：

| 名称 | 对应状态 |
|---|---|
| idle | 待机（必需，至少一帧） |
| think | 思考 |
| read | 阅读 |
| type | 编辑与回复 |
| search | 搜索与协作 |
| check | 测试、构建、Git |
| success | 任务完成 |
| failed | 任务失败 |
| walk-left / walk-right | 场景中的左右移动 |

每个动作最多 32 帧。缺少动作时使用**同一角色**的待机动画，不会掺入默认女孩。如果只提供一个行走方向，另一个方向会镜像播放；有不对称饰品的角色应分别提供左右动作。在预制和本地场景中，含行走动作的角色会自动走动、停留，并走回工作位置；没有行走动作的角色保持原地，避免滑动。动作预览页提供「向左走／向右走」按钮，可直接检查两方向的步态与边界。

## 场景配置

下面是只包含场景的完整配置：

```json
{
  "format": "dsh-toons-pack",
  "version": 1,
  "id": "my-room",
  "name": "我的房间",
  "scene": {
    "background": "background.png",
    "foreground": "foreground.png",
    "fit": "cover",
    "color": "#233f54",
    "centerX": 0.52,
    "footY": 0.94,
    "scale": 1
  }
}
```

`foreground` 可省略。前景在人物之后绘制，可以遮挡人物；它需要透明背景，尺寸必须与背景一致。首版场景包支持静态背景与前景，内置场景原有的动效仍然保留。

`fit` 可选 `cover`（居中填满并裁切）、`contain`（完整显示，空白处填底色）或 `stretch`（拉伸铺满）。默认 `cover`。建议使用宽幅图，将主要细节与人物活动区放在中央，以兼容窄窗口。

`centerX` 是人物工作与返回的位置，`footY` 是落脚基线，都是相对于最终舞台宽、高的比例，默认 0.5 和 0.94；它们不会随着图片裁切而改变。角色在工作位置两侧走动，画布边缘会限制实际站位，保证人物完整显示。`scale` 是人物倍率，默认 1，范围 0.25 至 2。舞台高度沿用插件现有布局，不由资源包改变。

本地场景使用预制模式。选择任意内置主题会退出本地场景，人物选择仍保留；退出后可以再次使用动态混合。只替换人物时仍可搭配动态场景。

## 单文件 JSON

也支持 `.json` / `.toons` 文件：在上述配置顶层增加 `assets`，将每张引用的图片写成 data URL。图片路径仍使用包内文件名作为键。

```json
"assets": {
  "character.png": "data:image/png;base64,这里是完整的图片编码"
}
```

这个片段需要合并到完整资源包对象中。普通的 `manifest.json` 因为不包含图片，不能单独导入；应和图片一起打成 ZIP。

## 容量与校验

单个包最多 20 MB，ZIP 解压后总计最多 32 MB，最多 32 个文件或目录；每张图片最多 8 MB、4096 × 4096，配置最多 128 KB。导入会先检查格式、文件、图片解码、动作帧范围和前景尺寸，再保存并应用。加载期间保留当前画面。

制作后可以在项目预览页切换动作、暂停任务、收起/展开并调整窗口宽度，检查动画对齐与场景裁切。示例素材由 `node scripts/create-resource-example.mjs` 生成，是本项目原创的像素测试素材。
