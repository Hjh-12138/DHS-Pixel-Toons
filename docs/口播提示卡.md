# DeepSeek Toons 口播提示卡

用途：约 2 分钟的项目展示，口播配合界面录屏。
依据：当前项目 0.1.10 的 README、界面文案及实现。

标题：AI 在写代码，像素小人也跟着上班

拍摄时只看每张卡的关键词，按自己的语气展开；接话句用于卡壳时找回节奏。

## 卡 1｜先给观众看动作（0–10 秒）

**关键词：AI 干活 → 小人上班**

接话句：「AI 在写代码，旁边这个像素小人，也跟着上班了。」

画面：先放女孩敲键盘，再接任务完成后的庆祝。画面同时保留聊天界面，让观众看懂角色的位置。

## 卡 2｜一句话说清项目（10–25 秒）

**关键词：DeepSeek Toons → Harness 插件 → 输入框上方**

接话句：「这个项目叫 DeepSeek Toons，装在 DeepSeek Harness 里，就能在聊天输入框上方加一个像素搭子。」

画面：展示完整界面，再放大动画区里的蓝发鲸鱼女孩。

## 卡 3｜动作跟着任务变（25–50 秒）

**关键词：读文件＝翻书 → 编辑＝敲键盘 → 测试＝检查 → 完成＝庆祝、待机**

接话句：「读文件的时候，她趴着翻书；编辑文件的时候，她敲键盘；跑测试就切到检查动作。任务完成后庆祝一下，再回到待机。」

画面：依次剪入阅读、编辑、测试、完成四种状态。让状态文字和动作一起出现，突出两者的对应关系。

## 卡 4｜换一个工作环境（50–65 秒）

**关键词：12 个主题 → 日光／暮色 → 日常、游戏场景**

接话句：「场景也可以换。现在有十二个像素主题，各有日光和暮色版本，书阁、茶室，或者罗德岛、蒙德，都能选。」

画面：打开「预制主题」菜单，切换两个差异明显的主题，每个停留两三秒。

## 卡 5｜把搭子换成自己的（65–85 秒）

**关键词：本地资源 → 自制资源包 → 人物、场景分别换 → 当前客户端保存**

接话句：「你也可以导入自己做的资源包，人物和场景能分别换。这里先试一下薄荷机器人和月光庭院，导入后就能直接用。」

画面：打开「本地资源」，点击「试用示例」，展示人物和场景一起替换；再展示两者各自的选择框。

补一句时可说：「资源保存在当前客户端，重新打开还能接着用。」

## 卡 6｜讲清动画的用量（85–105 秒）

**关键词：默认预制＝无额外模型调用 → 动态混合＝模型生成、额外 token → 失败回退**

接话句：「默认这些动画在本地播放，不额外调用模型。想让模型根据任务生成场景，可以切到动态混合，这时会产生额外 token，用量会显示在下面。生成失败就退回预制场景。」

画面：先在「本地资源」中点击「恢复默认」，再展示「预制场景／动态混合」菜单。若已有真实动态生成录屏，接入生成结果和「额外用量」。

## 卡 7｜收起，再落回体验（105–120 秒）

**关键词：收起／展开 → 少占空间 → 等待时看她忙活**

接话句：「想少占点空间，就把它收起来。展开以后，等 AI 干活的时候，也能看看这个小搭子在忙什么。」

画面：演示「收起／展开」，最后停在女孩待机眨眼的画面。

## 拍摄备忘

- 动作片段可以用项目预览页补拍；预览页的动态选项只演示回退，不调用模型。展示模型生成效果时使用真实 Harness 会话录屏。
- 自定义人物需要制作包含动作配置和图片的资源包；不能把任意单张图片直接当成完整角色导入。
- 「不额外调用模型」说的是预制动画；主任务本身的模型用量照常产生。动态用量显示的是 token，没有换算金额。
- 动作来自会话状态与工具事件；中文气泡是文字，没有语音朗读。
- 片尾小字可标注：「DeepSeek Toons｜基于 claude-toons 改造」。
