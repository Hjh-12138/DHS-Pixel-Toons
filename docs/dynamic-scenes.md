# 动态混合：模型编排精细场景

从 0.1.15 起，动画导演返回场景编排 JSON。程序复用 12 个精细像素主题，绘制固定角色、道具和特效。模型决定组合与气泡台词，返回内容不包含绘图代码、坐标、颜色或远程素材地址。

> [!IMPORTANT]
> 动态混合会把任务阶段、工具名称、路径／命令／检索词等短摘要、失败标记与角色人设发送给已配置的模型，并产生额外用量。尚无工具事件时，摘要可能包含用户输入的前 80 个字符；截短不等于脱敏。默认预制模式不为动画发送任务内容或调用模型。详情见 [README 隐私说明](../README.md#隐私说明)。

## 编排格式

```json
{
  "concept": "工坊里的检查任务",
  "theme": "workshop",
  "mood": "day",
  "action": "check",
  "props": [{"kind": "terminal", "slot": "left"}],
  "effects": ["scan"],
  "say": ""
}
```

`theme` 使用现有主题 ID；`mood` 为 `day` 或 `dusk`。动作支持 `idle`、`think`、`read`、`type`、`search`、`check`。成功、失败、取消和新任务状态由真实会话事件控制，旧编排不会覆盖新的任务阶段。

道具支持 `rice-bowl`、`token-cookie`、`watermelon`、`memory-jelly`、`book`、`terminal`、`server`、`lantern`，最多两件，各占 `left` 或 `right` 一个位置。道具使用一至数像素的细节绘制，在左右区域展示，给人物留出空间。

特效支持 `fireflies`、`steam`、`rain`、`scan`、`sparkles`、`bubbles`，最多两种，不重复。动画使用本地播放时钟；隐藏、收起或减少动态效果时随人物暂停。

`concept` 与非空 `say` 使用简体中文，文件名和命令保留原文。气泡通常不超过 24 个汉字，最多 60 个字符与 96 个显示列。模型基于 `src/character.ts` 中的人设自主创作，没有预设台词或阶段口吻模板。气泡在新场景开始后的前 12 秒展示；任务阶段变化或任务结束后隐藏，避免旧台词留在新任务上。

## 请求与回退

动态混合仍使用当前会话配置的模型，在任务开始或失败等事件触发时生成编排，沿用限流、超时与取消机制。默认预制模式不调用模型；本地资源场景继续使用预制模式。

预制场景至少展示 20 秒，生成结果可能先排队；动态场景上屏后至少展示 45 秒。短对话可能在结果上屏前结束，结束时取消生成并清理待展示结果。因此本次改造没有增加每句话都响应的独立气泡功能。

未知主题、道具或动作、占用同一位置的道具、重复特效、超量内容或额外代码字段都会被拒绝并回退到预制场景。旧绘图解释器继续兼容已有场景，新导演生成结果仅包含受限的素材选择。
