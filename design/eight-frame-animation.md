# 内置角色的八帧动作

十种动作各播放八帧。素材在 `assets/animations/`，每张图为四列两行；行走使用一张 `walk.png`，向右移动时在 Canvas 中水平镜像每一帧，保持相同的时序与身体大小。素材均由内置 imagegen 制作，原四帧图保留为造型参考，不再用于内置角色播放。

行走按二维侧视的一次可见迈步编排：触地、屈膝缓冲、后脚离地、抬脚内收、过髋高抬、向前摆脚、伸腿下落、接近落脚。第八帧抬起的前脚继续下落，接回第一帧。不能以左右腿名称、明暗或贴图变化充当新阶段。左右方向共用同一序列，避免独立生成造成朝向或阶段顺序不一致。

当前脚部验证忽略全部 RGB，只采样透明度形成轮廓，排除尾巴。以角色高度 80px 比较任意两帧，轮廓变化至少 20%，并要求每帧都有真实落脚点。原先用腿的颜色区别重复姿势的版本无法通过这一检查，未采用。

每帧按实际脚底登记纵向根位置，按固定格子中心定位横向根位置；裁切寻找各行自己的透明缝隙。行走不添加整个人物上下跳动，避免抬起原本落地的脚。每个动作采用固定像素比例，八帧动作总时长沿用原先配置，行走为每帧 75ms、一轮 600ms。

任务完成按准备、蓄力、起身、欢呼、落地、站稳、火花初绽、烟花展开推进。烟花在第七、第八帧由 Canvas 绘制为两个连续阶段；最后一个人物姿势登记镜像，以保持围裙蝴蝶结与鲸尾方向一致。

最终制作依据：

- `eight-frame-action-prompts.txt`：待机、思考、翻书、打字、检查和失落的动作过程；其中旧的行走描述已被下述二维版本替代。
- `eight-frame-success-prompt.txt`：完成动作的八个连续阶段。
- `eight-frame-search-prompt.txt`：同一只手完成一次小范围扫描。
- `walking-eight-frame-2d-prompts.txt`：行走的二维轮廓与脚轨迹规则。
- `walking-eight-frame-padding-prompt.txt`：只补齐右边缘的鲸尾尖，保留已验证的八个腿脚姿势。

可用 `npm run preview` 查看实际插件组件；本次逐帧审查页在 `work/eight-frame/action-review-server.mjs`，展示真实时长播放、八帧静态顺序和去色脚部轮廓。
