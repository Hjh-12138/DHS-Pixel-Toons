# DeepSeek Toons 角色方案

## 主角与视觉设定

用户指定参考图：`E:\heishou\minimax h3 mx\deepseek_girl\deepseek三视图.png`。

动画主角采用参考图中的少女，转为像素风 Q 版。保留深蓝长发及浅蓝发梢、弯曲呆毛、白色蕾丝发箍、蓝色眼睛、侧面蓝色蝴蝶结、鳍状侧发、深蓝女仆裙、鲸鱼图案围裙、鲸尾和背部白色蝴蝶结。衣裙、头发和尾巴的形状优先保证小尺寸辨识度，蕾丝和金色装饰简化。

角色比例约 2.5 头身。逻辑帧尺寸以 64×80 像素为起点，实际帧尺寸在预览与低分辨率验证后固定。使用透明背景、有限色板、明确的像素轮廓和最近邻缩放。

`deepseek-girl-pixel-turnaround.png` 是内置 image_gen 工具依据参考图生成的正面、左侧面、背面设定预览。此图尚不是帧尺寸、对齐位置和色板均已验证的生产用 sprite atlas。

## 与移植方案的衔接

延续独立 `dsh-toons` 原生插件包、官方聊天界面动画带、先预制后动态的实施顺序。首版已经完成 Web 接入与无网络会话联调，目标版本为 Harness 0.2.0-rc.2；Desktop 载体待实测。

角色使用固定素材和动作库。场景模型只能选择角色动作、位置、朝向、表情和道具，不能重新绘制角色；新场景与预制场景共用同一角色素材。

浏览器动画以 Canvas 和 Web Worker 为基础。Sprite 采用最近邻缩放，提供头部、双手、脚底、尾部及气泡锚点，便于绑定工具、帽子和气泡。角色独立于场景背景的绘制风格。

上游 `clawd()`、`clawd3d()` 的调用及身体锚点需要适配。保留兼容入口并映射到角色动作库，按场景检查尺寸、道具位置与遮挡。不能只替换一张图片后就宣称所有预制场景完成兼容。

首阶段验证 2D 场景；3D 场景中的主角采用投影到场景位置的 2D sprite，后续验证景深缩放和遮挡。无需让场景模型临时生成角色 3D 网格。

## 动作素材计划

| 用途 | 动作与帧数起点 |
|---|---|
| 等待与思考 | 待机呼吸 4 帧、眨眼 2 帧、思考 4 帧 |
| 移动与查找 | 侧面行走 6 帧、搜索观察 4 帧 |
| 阅读与编辑 | 读书 4 帧、敲键盘 4 帧 |
| 任务成功 | 庆祝 4 帧 |
| 工具失败 | 惊讶 2 帧、失落 4 帧 |

动作制作前固定帧尺寸、脚底基线和锚点；左右朝向涉及饰品不对称时单独检查，避免直接镜像改变角色设定。帧数为规划值，按动作可读性调整。

## 验收要求

- 正面、侧面、背面与动作帧使用同一角色比例和色板，头发、服饰、鲸尾保持一致。
- 低分辨率预览中仍可辨认眼睛、发箍、鲸鱼围裙和尾巴。
- 所有动作保持稳定帧尺寸与脚底基线，无裁切、漂移或饰品闪烁。
- 动作、气泡和道具与场景同步，阅读、测试、成功和失败状态可区分。
- 生成场景不会改变角色外观；异常场景回退到已验证的预制动作。
- 开关动画、切换会话、结束任务及后台暂停行为遵循原插件方案。
